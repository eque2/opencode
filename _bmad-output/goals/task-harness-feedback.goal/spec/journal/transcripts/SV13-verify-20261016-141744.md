  500 ms settle), and that after the release the store holds `task.ready` / `task.verified` / `task.repeated` with
  `at` at or after the release, and the payload (head with the builder's file, the verdicts, the reason).
- And a session that no supervisor owns records nothing and the tool says so: test 4 asserts both tools answer
  "No task harness run owns this session. Nothing was recorded." with `valid: false`, `limitOf` and `repetitionStop`
  are none, the store does not change and the run's owner holds no event. Test 5 also asserts this for a session of
  an ended run.

## Choices
- EXPERIENCE's "Closing summary" mock prints no `run.reason` lines under the outcome line; AD-18 says the summary
  prints `run.reason`. The tasks.md case says "content per EXPERIENCE": the outcome line carries the first reason line
  for a stop (rule 2), and the Stopped and Not run sections hold what `run.reason` lists.
- The glyphs come from the tags (dead ⊘, blocked ⊖, other stops –, a failed scenario ✗, not run ○), so no table keyed
  by state names enters src/task (AD-17).

## Test cases

1. **Happy Path — one actor per instance, stopped with the reactive root, follows a rewritten status.** PARTLY
   COVERED. "each plugin instance has its own view actor" proves per-instance state (a shared actor or a module
   state would fail it). "follows a new status file through its one-second poll" proves the rewrite is followed.
   GAP: "an unloaded plugin's view actor stops" asserts only on SDK requests and toasts. Both come from Solid
   reactions (the session-list resource, the Ticker's `createEffect`) inside the root that `dispose()` tears down,
   so the test passes with an actor that never stops (M1). Nothing asserts that the actor itself stops.
2. **State Transitions — root, target, armed/disarm, the 500 ms tail, the Peek polls as machine state.** COVERED.
   The route test (children read for `ses_other`, keyed on the machine's `root`); the ctrl+x w test (the route
   carries the machine's `target`); the Peek test on a SimulatedClock (children 1→1→2, messages 1→2→2 at 1.5 s and
   2 s); the tail test on a SimulatedClock (no new text before the 500 ms tick, new text after it); the machine's
   stop-key tests; the source scan (no createSignal, poll(, Effect.sleep, Effect.repeat, Schedule., setInterval,
   LIVE_WINDOW in index, watch, peek, store, view). A grep of src/task-ui finds no other timer or signal except the
   one `fromActor` signal that AD-16 allows.
3. **Permissions — Tab, esc twice and the watch keys only while live and owned; no status → Tab to the agent.**
   PARTLY COVERED. Tab: live+owned taken, live+not owned to the agent, still+owned to the agent (plugin UI3 test),
   ended to the agent (task-ui test); no status file → Tab to the agent. These are strong. esc twice: live+owned
   aborts; ended after arming stops nothing; still is covered through the same `view.live()` gate that the still
   Tab case proves. GAP: no test presses esc when the root does not own the run. `wired()` hardcodes
   `owns: () => true`, so the `!ctx.owns()` check in the esc gate is never exercised (M2). The path is reachable:
   with the watch on, a move to another session in the same directory that owns no harness session, while the run
   stays live, leaves `watching`, `live` and `onRoot` true, so without the check esc twice would abort that session.
   The ctrl+x w toggle acting on a still run is read as a view key, not a run key (EXPERIENCE "Run stands still"),
   and was not counted as a gap.
4. **Boundary — kv persistence and the invalid-value fallback; /task-design switches all seven.** COVERED. "a chosen
   design survives a reload…" (6 kept, 9 → 1); "the plugin registers /task-design and switches to each of the
   seven designs" (each pick toasts, renders and reopens with the new current).
5. **Error Propagation — esc twice aborts and toasts; the watch toggle collapses the Board.** COVERED. Exact toasts,
   `aborted == [ses_root]`, the restart line with the run path; the Board collapses, the watch turns on, the route
   carries `watch: b2`, and the toggle back clears it.
6. **Concurrency, Timing.** N/A.
7. **UI21 — the idle band names T9 with its trust command; an external id gets none.** COVERED. Exact band text for
   the outside T9 wait; "The run waits on T1.1." with no `/task trust` for the external region.
8. **Permissions — stop.key armed while live: the run ends, or route.changed moves, before the second esc → no
   stop.** COVERED. End-to-end for the run end (no abort, one toast). The route move is covered by the machine test
   (route.changed disarms, no second `stop.run`) and the route test, which proves index.tsx's `route.changed`
   reaches the machine.
9. **State Transitions — poll, LIVE_WINDOW and the view signals leave store.ts; watch.tsx reads tags.** COVERED. The
   store exports no `poll`, `LIVE_WINDOW`, `ACTIVE` or `createView`; the audit passes with every T4.3 interim entry

## ADV-12 — each changed H-check expectation and its reason
- H8 (crash and resume): adds "the resumed run's path is the spec's path". Reason: AD-6 — a resume continues the
  stored slice of the same `/task` path; the run supervisor records `run.resumed { path }`. Before, H8 accepted a
  restart that started any run. This tightens the check.
- H12 (stream stall): the wait now needs "a stall entry of T1.1 in history" (it accepted a new builder request OR a
  stall/idle entry), and after the run a T1.1 builder request must follow the hung one, with attempts still 1.
  Reason: AD-11 — the task supervisor's stall timer cuts the silent turn and records `task.stalled`, which writes a
  history entry, and prompts the same attempt again (D2: a stall spends no attempt). This tightens the check.
- `arms/status.ts` (301137a225, T1.14): the state unions add `blocked` (tasks, scenarios) and `cancelled`
  (scenarios). Reason: D2/D3 — the machine shows a task whose dependency died as `blocked`. Types only.
- The AD-13 fields (`tags`, `title`, `aliveAt`, and the rest): the reader's `shape()` checks only the contract's
  top-level shape (`run.state` a string; `tasks`, `obligations`, `scenarios` objects; `history` an array) and ignores
  every other field, so they are optional to it. The BUILD-6 run read status files that carry them and passed H1–H16.
